**MatchLR** is an R framework for predicting candidate receptors for orphan
immune ligands. It fuses ligand–receptor interactome evidence, single-cell
expression, cell-surfaceome annotation, Pfam protein-domain compatibility,
binding data, and AlphaFold structural evidence, combining a trained XGBoost
binding-probability ensemble with CellChat via reciprocal rank fusion to
prioritize receptors.

_In active development — a public repository is not yet available._
