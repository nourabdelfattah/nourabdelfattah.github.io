**RNAseqWizard** is a Shiny application for end-to-end bulk RNA-seq analysis
without writing code: import counts, run quality control, perform differential
expression, explore interactive visualizations, and carry results into pathway
analysis.

- **Code:** [github.com/nourabdelfattah/RNAseqWizard](https://github.com/nourabdelfattah/RNAseqWizard)
- **Run it locally:**

```r
shiny::runGitHub("RNAseqWizard", "nourabdelfattah")
```
